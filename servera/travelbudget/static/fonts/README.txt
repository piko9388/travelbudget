글꼴을 바꾸고 싶을 때만 쓰는 폴더입니다. 비워 두어도 정상 동작합니다.

이 폴더에 아래 두 파일을 넣으면 화면 글꼴이 자동으로 바뀝니다.

    ui-400.woff2    (Regular)
    ui-700.woff2    (Bold)

파일이 없으면 index.html 의 @font-face 선언은 조용히 무시되고
윈도우 기본 한글 글꼴(맑은 고딕)로 렌더됩니다. 오류도 나지 않습니다.

왜 필요한가
    맑은 고딕은 굵기가 Regular / Bold 둘뿐이라 위계를 굵기로 만들 수 없고,
    12px 아래에서 한글 획이 붙어 뭉개집니다.
    본문용으로 설계된 글꼴을 넣으면 두 가지가 함께 해결됩니다.

무엇을 넣나 (예시)
    Pretendard  — SIL Open Font License 1.1, 상업적 사용·임베딩 허용
    그 외 사내에서 사용이 허가된 본문용 고딕 계열

    * 반드시 사내 폰트 정책과 라이선스를 먼저 확인하세요.
    * 한글 전체를 담으면 파일이 큽니다. KS X 1001 2,350자 서브셋(woff2)이면
      보통 300~500KB 이고, 최초 1회 로드 후 브라우저가 캐시합니다.
    * 외부 CDN 주소를 쓰지 마세요. 사내망에서 차단되면 글꼴이 안 나옵니다.
      반드시 이 폴더에 파일로 두어야 합니다.

넣은 뒤 확인
    Ctrl+F5 로 새로고침 → 글꼴이 바뀌었는지 눈으로 확인
    되돌리려면 두 파일을 지우고 다시 새로고침하면 됩니다.
